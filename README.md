# All classworks on C# for my UNI

- every task is in its file with date of practice as filename or separate dated directory

- all classes are used in ```Program.cs``` and sometimes are commented out

- in nearly every file tabsize is 2 spaces

## Build and Run the whole project (not including dated directories)
to build use
```
$ cd Classworks
$ dotnet build
```

to run use
```
$ cd Classworks
$ dotnet run
```

## Build and Run subproject in a dated directory
to build use
```
$ cd Classworks
$ cd <dir_name>
$ dotnet build
```

to run use
```
$ cd Classworks
$ cd <dir_name>
$ dotnet run
```
